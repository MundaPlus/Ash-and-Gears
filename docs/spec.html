Chapter 00

Overview

Status: DRAFT v0.1 (2026-10-09). Code name: wasteland-colony. Title: picked later.

Elevator pitch

The bombs fell. The survivors joked about it. Lead a small group of survivors in a ruined world. Build a home in the rubble. Keep them fed, sane and alive. Salvage the old world's machines. Slowly let the machines do the work. Then reach for a bigger goal: light, rescue or the stars.

Inspirations

Game What we take
RimWorld Indirect control, small cast with stories, storytellers, mood, drafting
Dwarf Fortress Underground layers, deep simulation, emergent chaos
Factorio Production chains, belts, power, the joy of automation
Fallout 1/2 Post-apocalyptic world, dark humor, factions, scavenging

Design pillars

  1. Every survivor is a story. 3–20 survivors. Each has a name, a past, traits, relationships and a body that can break.
  2. From scrap to machines. The colony starts with bare hands. Tech replaces labor step by step. Late game, survivors manage machines, not haul rocks.
  3. The wasteland pushes back. Raiders, mutants, radiation and the survivors themselves create the drama.
  4. Laugh so you do not cry. Dark humor in names, events, item descriptions and mood thoughts. The world is grim. The writing is not solemn.
  5. Readable on a phone. Desktop-first, but every system must be playable on a phone screen.

Target player

  • Fans of RimWorld, Dwarf Fortress, Factorio, Oxygen Not Included.
  • Plays sessions of 20 minutes (mobile) to 3 hours (desktop).
  • Likes stories that come from systems, not scripts.

Platforms

Platform Phase
Web browser (desktop) Demo
Web browser (mobile, PWA) Demo
Android / iOS app (Capacitor) After demo
Desktop app / Steam (Tauri or Electron) Optional, after demo

Game modes

  • Story mode: choose one of three storylines (see 07-story.md). Ends with a win or a colony wipe.
  • Sandbox: no goal. Play forever.
  • Scenarios: fixed maps with goals and a score.
  • Permadeath: an option for any mode. One autosave. No reload.

Core loop

  1. Survivors gather, salvage, build, farm and craft.
  2. The colony grows. It faces events, raids and disasters.
  3. Research and salvaged blueprints unlock new tech.
  4. Tech unlocks automation. Survivors are free for expeditions and defense.
  5. Expeditions on the world map bring blueprints, trade and allies.
  6. The story goal advances.

Scope phases

Phase Content
Demo Home map, 1 underground layer, 3 survivors, core needs, building, farming, water, radiation event, mutant raid, research tier 1, power, first belt and crafter, save/load
Alpha All survivor systems, raiders, factions, world map, expeditions, trade, outposts, 2 underground layers, tech tiers 1–3
Beta Three storylines, scenarios, robots and tier 4 tech, full music, mod loader, mobile app
1.0 Balance, polish, more languages, optional Steam build, optional cloud saves

Out of scope

  • Multiplayer.
  • Full z-levels like Dwarf Fortress (we use a few separate layers).
  • Animated sprites with many frames (texel-studio makes single frames; we use small procedural motion instead).

Chapter 01

Survivors (colonists)

Count

  • Start: 3 survivors (scenario can change this).
  • Soft cap: 20. Storyteller lowers join events above 15.
  • New survivors join by: wanderer events, rescue, recruit prisoners, trade, story events, births (post-alpha, optional).

Identity

Each survivor has:

  • Name and nickname (generated, sometimes funny: "Two-Can Mendez").
  • Age, gender (cosmetic and pronoun only), portrait built from parts.
  • Backstory: one pre-war job + one post-war life. Each gives skill bonuses, maybe a work restriction ("Ex-Banker: will not do dumb labor").
  • 1–3 traits.
  • 10 skills.
  • Body with parts (health).
  • Relationship list.
  • Thought log (recent mood thoughts).

Needs

Need Drops when Fix Low effect
Hunger Always Eat food Mood penalty, then starving damage
Rest Awake Sleep in bed (better), on floor (worse) Slow work, then collapse
Thirst Always Drink clean water Faster than hunger. Dirty water: disease risk, rad dose
Recreation Working Chat, games, booze, jukebox Mood penalty
Comfort Standing, sitting on floor Chairs, beds Small mood penalty
Beauty Ugly or dirty rooms Clean rooms, decoration Small mood penalty
Outdoors Inside for long Go outside (if air is safe) Small mood penalty

Thirst is a confirmed addition for the setting (user approved). Clean water is a key resource.

Mood

  • Mood is 0–100. It is the sum of base + all active thoughts.
  • Thoughts have value, duration and stack limits. Examples:
  • "Ate a fine meal" +5. "Ate raw mutant meat" −7. "Ate raw mutant meat (Iron Stomach)" +2.
  • "Slept outside in acid rain" −8. "Friend died" −20. "Saw a corpse" −3.
  • Mental breaks below thresholds:
  • Minor (< 35): sulk, binge eat, hide in room, rant at the sky.
  • Major (< 20): drunken rampage, food hoarding, insult spree, "tries to start a cult".
  • Extreme (< 5): violent rage, run away into the wasteland, destroy a machine.
  • Inspiration above 85 (chance): faster work, better crafting, a free research boost.

Skills (0–20)

Shooting, Melee, Construction, Mining, Cooking, Farming, Crafting, Medicine, Scavenging, Technology (research + machines), Social.

  • Skills grow by use. Skills slowly decay above level 10 when unused.
  • Passion (none / interested / burning) changes learning speed and mood from doing that work.

Traits (examples, full list in data)

Trait Effect
Iron Stomach Can eat raw and rotten food without penalty
Rad-Hardened 50% less radiation dose
Paranoid Mood penalty without walls; bonus when guarding
Optimist / Pessimist Base mood +/−
Hoarder Happy near full stockpiles
Tinkerer Faster machine repair; sometimes "improves" machines (random effect)
Lazy 20% slower work; more recreation need
Night Owl Prefers night work
Cannibal Human meat is fine. Others dislike them
Lucky Idiot Low skills; survives things they should not
Pyromaniac Random fire-starting break
Old-Worlder Remembers before the war. Tech bonus. Sad about everything

Health

  • Body parts: head, torso, 2 arms, 2 hands, 2 legs, 2 feet, eyes, internal organs (simplified: heart, lungs, stomach, liver).
  • Injuries: cut, bruise, gunshot, bite, burn, fracture. Each has bleed rate, pain and heal time.
  • Conditions: infection, disease (from dirty water/food), radiation sickness (stages), hypothermia, heatstroke, addiction.
  • Capacities derived from parts: moving, manipulation, sight, consciousness, breathing.
  • Radiation dose is a counter. It slowly drops. Stages: none → mild (nausea) → serious (weakness) → severe (organ damage) → lethal. Rad-Away-style medicine lowers it.
  • Medicine: bandages, scrap medkits, old-world medkits. Doctor skill sets quality.
  • Prosthetics: scrap limbs (weak, cheap) → old-world bionics (strong, rare, from expeditions).

Relationships

  • Opinion of each other survivor: −100 to +100. Changes from chats, insults, shared events, traits.
  • Relation types: friend, rival, lover, spouse, ex, family.
  • Events: romance, breakups, fights, grief for dead.
  • Social skill improves chats and trade.

Work

  • Work types: Doctor, Firefight, Patient/Rest, Cook, Hunt, Construct, Grow, Mine, Salvage, Smith/Craft, Tech (research + machines), Haul, Clean, Guard.
  • Work priority grid: survivors × work types, values 1–4 or off. Simple mode: on/off only.
  • Schedule: hours set to sleep / work / recreation / anything.
  • Survivor can be drafted (see 06-combat-threats.md).
In the first demo

Hunger, rest, thirst, mood with ~20 thoughts, minor breaks only, 6 skills, 8 traits, simple health (HP per body region, bleeding, rad dose), no relationships beyond opinion number.

Chapter 02

World

Home map

  • Size options: small 128×128, medium 200×200 (default), large 256×256 tiles. Mobile default: small.
  • One tile = one survivor-sized cell.
  • Map generated from a seed + the world-map site (biome, ruin density, water, hills).

Surface terrain

Terrain Notes
Cracked asphalt Fast walking, no farming
Dirt / dry soil Farmable (poor)
Rich soil (rare) Farmable (good)
Sand / ash Slow, no farming
Rubble Slow; can be cleared for scrap
Shallow water / sludge Dirty water source, slow
Toxic pool Damages, rad source
Rock outcrop Mineable, entrance to underground

Map features

  • Ruins: collapsed houses, a gas station, a supermarket, a factory, a car park. Can be salvaged for scrap, parts, sometimes blueprints and loot crates.
  • Wrecks: cars, buses, a crashed plane (rare). Salvage gives metal and parts.
  • Dead trees and mutant shrubs: wood source.
  • Resource deposits: scrap piles, stone, coal seam (underground), old fuel tank.
  • Hidden things: a sealed bunker hatch, a buried cache (found when digging).

Underground layers

  • Demo: 1 layer ("Basement / Mine").
  • Full game: 2–3 layers. Proposed: L-1 Basements and sewers, L-2 Mine and old metro, L-3 Deep bunker (story).
  • Layers are separate maps with the same size. Stairs, ladders and lift shafts link them.
  • Underground is solid rock by default. Survivors dig tunnels (Mining work).
  • Underground rooms are safe from radiation clouds, weather and most raids. They are dark (need lights) and cold/hot by depth.
  • Hazards: cave-ins (need supports), flooding, gas pockets, burrowing mutants, sewer nests.
  • Player switches the visible layer with a button or key (PageUp/PageDown).

World map

  • Hex or grid map of the region, about 60×40 cells. Generated per game.
  • Biomes: ash plains, irradiated forest, ruined city, dry riverbed, glowing crater, mountain pass, coast.
  • Sites:
  • Ruins to scavenge (loot, blueprints, danger level).
  • Faction towns (trade, quests, diplomacy).
  • Story locations (one chain per storyline).
  • Outposts (player-built).
  • Roaming threats (raider bands, mutant herds) that move on the map.
  • Seasons change the world map (winter closes passes, spring floods rivers).

Expeditions

  • Player chooses survivors, supplies and a vehicle (on foot → cart → truck).
  • Travel time depends on distance, terrain, vehicle and load.
  • At the site, two modes:
  • Auto-resolve (default): a short text log with 1–3 choices per event.
  • Tactical map (optional, for big sites): a small generated map where the player controls the team directly. Alpha ships auto-resolve; tactical maps come in beta.
  • Rewards: scrap, parts, blueprints, recruits, story items. Risk: injury, death, capture.
  • The home colony keeps running with fewer hands.

Factions

Faction Type Notes
The Rust Knights Raiders, militaristic Worship old cars. Frequent raids
The Shiny Smile Corp Traders Still selling insurance to the dead. Neutral
The Children of the Glow Cult Love radiation. Can be allies or a nightmare
The Last Bureaucrats Remnant govt. Demand paperwork. Have old-world tech
Mutant Herds Not a faction Animal behavior, territorial
  • Each faction has goodwill −100 to +100 with the player.
  • Goodwill changes by trade, gifts, quests, raids, prisoners.
  • Factions can be hostile, neutral or allied. Allies send help when asked.

Trade

  • Caravans visit the home map. Player can also visit faction towns.
  • Currency: "Scrip" (old-world store coupons). Barter also works. (Bottle caps are avoided because Fallout uses them.)
  • Prices depend on faction, goodwill and Social skill of the negotiator.

Outposts

  • Built on world-map sites with a survivor team (1–3).
  • Types: mine, farm, scrap yard, water pump, radio relay (story).
  • Produce resources every few days. Send caravans home or need a road/vehicle.
  • Can be raided. Simplified sim (numbers, not a full map).

Weather and seasons

  • 4 seasons. Day length and season length are set at game start. Default: 1 day = 6 real minutes at 1x, 15 days per season.
  • Weather: clear, overcast, dust storm, acid rain, heat wave, cold snap, radiation cloud.
  • Temperature changes by season, weather, day/night and layer depth.
In the first demo

Medium home map, surface + 1 underground layer, ruins/wrecks/trees/scrap, clear/rain/radiation cloud weather, 1 season cycle. No world map.

Chapter 03

Building

Orders (designations)

Player marks work. Survivors do it.

  • Build (blueprint placed, materials hauled, then constructed).
  • Deconstruct (own buildings: returns most materials).
  • Salvage (ruins and wrecks: returns scrap, parts, random finds).
  • Mine (rock, underground).
  • Clear rubble.
  • Cut plants / harvest.
  • Haul, clean, hunt, tame (post-demo).
  • Cancel.

Structures

Category Examples
Walls Scrap wall, wood wall, brick wall, concrete wall, reinforced wall
Doors Curtain, scrap door, metal door, blast door (powered, late)
Floors Dirt (none), wood planks, scrap tiles, concrete, sterile tiles
Roofs Auto-added over enclosed rooms up to 6 tiles from a wall. Can be removed
Supports Underground: wooden prop, steel beam. Prevents cave-ins
Stairs Ladder, stairs, lift (powered)
  • Materials change HP, build time, beauty and insulation.
  • Every structure has HP and can burn or break.

Rooms

  • A room is an area fully enclosed by walls and doors, with a roof.
  • Found by flood fill. Recalculated when walls or doors change.
  • Room types are auto-detected by contents: bedroom, barracks, kitchen, dining room, workshop, hospital, storage, lab, rec room, prison.
  • Room stats: size, beauty, cleanliness, temperature, air (see radiation). Stats give room quality: Awful → Impressive. Quality gives mood thoughts.

Temperature

  • Each room has one temperature value. Outdoors uses the weather temperature.
  • Heat moves through walls (insulation by material), open doors and between rooms.
  • Heat sources: campfire, stove, heater (fuel or power), survivors (tiny), fires.
  • Cooling: cooler (powered), ice box (early), vents to outside.
  • Survivor comfortable range: 16–26 °C by default. Clothes widen it.
  • Food rots faster when warm. Freezer rooms stop rot.

Air and radiation shelter

  • A room is sealed if it is enclosed, roofed and has no open door to outside.
  • During a radiation cloud: outdoors and unsealed rooms get radiation. Sealed rooms stay clean.
  • Late tech: air filters let a room stay clean even with its door used often.

Furniture and production buildings

  • Beds (bedroll → scrap bed → real bed → hospital bed).
  • Tables, chairs, shelves, lamps, decorations ("Velvet Elvis painting").
  • Workbenches: scrap bench, kitchen stove, smithy, tailor, chem bench, electronics bench, research desk.
  • Storage: shelves (more items per tile), fridge (powered).

Zones

  • Stockpile: holds items. Filters by item type. Priority low → critical.
  • Growing zone: crop type chosen per zone.
  • Home area: survivors clean and firefight only here.
  • Allowed area: limits where survivors may walk.
  • Dumping zone: for corpses and junk.

Salvage and scrap economy

  • Ruins on the map are full of scrap. Salvage is the main early resource.
  • Salvage result: scrap metal, wood, cloth, components (rare), and a loot roll (food cans, meds, weapons, blueprints).
  • Scavenging skill raises yield and loot roll chance.
  • Some ruins collapse when salvaged too fast (small danger).
In the first demo

Build, deconstruct, salvage, mine, clear rubble, harvest. Scrap/wood/stone walls, doors, floors, auto-roof. Rooms + types (bedroom, kitchen, storage, workshop). Temperature (simple). Sealed rooms vs radiation. Stockpile + growing zones. Beds, table, chair, lamp, 4 workbenches.

Economy, food and water

Resources (base)

Resource Source Use
Scrap metal Salvage, wrecks, rubble Walls, tools, machines
Wood Dead trees, salvage Early building, fuel
Stone Mining Walls, stoves
Cloth Salvage, fiber crops Beds, clothes, bandages
Components Rare salvage, crafting (tier 2) Machines, weapons
Coal Underground Fuel, steel
Steel Smelting scrap + coal Better machines, walls
Fuel Old tanks, refinery (tier 3) Generators, vehicles
Chemicals Salvage, chem bench Medicine, explosives, fertilizer
Electronics Electronics bench (tier 2+) Automation, robots
Old-world parts Expeditions only Key research nodes, story

Production chains (examples)

  • Scrap → (scrap bench) → scrap tools / scrap walls.
  • Scrap + coal → (smelter) → steel.
  • Steel + components → (machine shop) → gears, pipes, motors.
  • Motors + electronics → (assembler) → conveyors, crafters, robots.
  • Crops → (stove) → meals. Meals → better mood.

Food

Food Quality Notes
Canned food (pre-war) Simple From salvage. Does not rot. Limited
Raw crop Raw Mood penalty
Raw meat (mutant) Raw Big mood penalty, disease risk
Simple meal Simple Stove
Fine meal Fine Good cook + 2 ingredients
Nutrient paste Awful Late machine. Very efficient. Survivors hate it
Booze (moonshine) Drug Recreation, addiction risk
  • Food rots by time and temperature. Fridges and cold rooms slow it.
  • Food poisoning chance from cook skill and room cleanliness.

Farming

  • Crops: glowcorn (fast, low yield), scrub potato (cold-safe), rust-berry (mood food), fiber weed (cloth), med-root (medicine), tox-lily (chemicals).
  • Growth depends on soil, light, temperature and water.
  • Hydroponics (tier 2): indoor, powered, no soil needed. Safe from radiation.

Water

  • Water types: dirty, clean, contaminated (radioactive).
  • Sources: dirty pools, rain collector (clean unless rain is acid or radioactive), well (clean, may become contaminated), water pump (tier 2), purifier (tier 2, makes clean from dirty or contaminated).
  • Water is stored as an item (jugs/barrels) in early game, as a fluid network (tanks + pipes) from tier 2.
  • Drinking dirty water: disease chance. Contaminated water: rad dose.

Radiation cloud event

  • Storyteller event. Duration: a few hours to days in-game.
  • During the cloud: all survivors outside take rad dose per tick.
  • Contamination: when the cloud ends, the following become contaminated for one season:
  • Crops in outdoor growing zones (and soil of those zones).
  • Food and water items stored outside or in unsealed rooms.
  • Open water sources (pools, rain collectors, wells without cover).
  • Items in sealed rooms stay clean. This is the main reason to build sealed storage.
  • Contaminated food/water can be eaten in desperation (rad dose) or cleaned (purifier, decon shower for items — tier 2).
  • Warning: storyteller gives a short alert (half a day) before most clouds. Hard storytellers sometimes do not.
In the first demo

Scrap, wood, stone, cloth, components, steel, coal. Canned food, raw crops, simple meal. Glowcorn, scrub potato, fiber weed. Dirty pool, rain collector, well, jugs. Radiation cloud with contamination for one season. Rot by temperature (simple).

Chapter 05

Automation and tech

Principle: progressive automation

The colony starts with bare hands. Each tech tier moves a kind of work from survivors to machines. Survivors become operators, defenders and explorers.

Tier Name Power Logistics Production
0 Scrap Age None (fire, muscle) Survivors haul by hand Hand-worked benches
1 Salvage Age Scrap generator (wood/fuel), wires, batteries Hand carts, first conveyor belt Smelter, powered benches (faster)
2 Machine Age Solar panels, wind turbine, fuel generator Belts, splitters, loaders (bench in/out), pipes for water Auto-crafter (recipe set, no survivor), pump, purifier, hydroponics
3 Old-World Age Geothermal, fuel refinery Hauler drones, sorters, underground belts Assembler lines, refinery, auto-kitchen (nutrient paste), turrets with ammo belts
4 Reborn Age Restored reactor (story) Robot workers (build, mine, farm) Robot factory, bionics, story machines

Power

  • Power network: generators, consumers and batteries linked by wires (or adjacency for conduits).
  • Network has supply (W) and demand (W). Shortage → consumers run slower or stop by priority.
  • Machines can break down. Repair needs components and Tech skill.
  • Underground: wires go through ladders/stairs links.

Logistics

  • Conveyor belt: moves items 1 tile per X ticks. Directional. Tier 1 basic, tier 2 fast.
  • Loader / unloader: puts items into or takes them out of a bench, crafter or stockpile.
  • Splitter / sorter: splits or filters items (tier 2/3).
  • Pipes (tier 2): water and fuel. Tanks store fluid.
  • Hauler drones (tier 3): fly items between stockpiles and machines. Need charge pads.
  • Belts and survivors share the same item system. A survivor can pick items off a belt.

Auto-crafters

  • Placed building with a recipe. Input from loaders or survivors. Output to a belt or the tile.
  • Speed and quality: lower quality than a skilled survivor at first; tier upgrades raise it.
  • This creates a real choice: skilled hand-crafted gear vs mass machine output.

Robots (tier 4)

  • Robot types: builder, miner, farmer, hauler, guard.
  • No mood. Need charge and repairs. Can be hacked by raiders (event) — dark humor: "Your robot joined the Rust Knights."

Research

  • Research desk (tier 0), lab (tier 2), old-world terminal (tier 3).
  • Research points from survivors (Technology skill) at a desk.
  • Tree: about 60 nodes in the full game, grouped by tier and branch (Power, Logistics, Production, Food & Water, Medicine, Defense, Vehicles).
  • Blueprints: key nodes need a blueprint item before research can start. Blueprints come from salvage (rare), expeditions, trade and quests.
  • Example: "Auto-crafter" needs blueprint "Factory Control Manual". "Reactor Restart" needs "Reactor Schematics" (story item).
In the first demo
  • Tier 0 and tier 1 complete, plus one tier 2 machine (auto-crafter, basic).
  • Research desk with about 10 nodes. 1 blueprint-gated node (blueprint found in a ruin on the home map).
  • Scrap generator, wires, battery, lamp, powered bench, conveyor belt, loader, auto-crafter.

Chapter 06

Combat and threats

Combat model

  • Real-time, ticks. Pause allowed at any time.
  • Drafting: player drafts survivors. Drafted survivors take direct move and target orders. Undrafted survivors flee or fight back by trait.
  • Ranged hit chance = shooter skill + weapon accuracy at range − target cover − target movement − light/weather.
  • Cover: low walls, sandbags, wrecks, rubble, trees. Cover gives a block chance by direction.
  • Damage hits a body part. Armor reduces it by type (sharp, blunt, heat, radiation).
  • Morale: enemies flee when losses or pain are high.

Weapons (examples)

Tier Melee Ranged
0 Pipe, plank with nail, knife Slingshot, thrown bricks
1 Machete, sledgehammer Pipe pistol, crossbow, scrap shotgun
2 Chainsaw, shock baton Hunting rifle, SMG
3 Power fist Assault rifle, flamethrower
4 — Old-world laser (rare), rocket launcher

Defenses

  • Walls, doors, sandbags, spike traps, tripwire bells (early).
  • Turrets (tier 1: scrap turret, needs power; tier 2: ammo-fed by belt; tier 3: auto-cannon).
  • Mines and IED traps (chemicals).
  • Late game: defense is mostly automated. Survivors repair and refill.

Threats

Raiders and factions

  • Raid size from colony wealth and storyteller.
  • Raid types: assault, siege (they dig in), sappers (dig through walls), kidnap, theft.
  • Captured raiders can be recruited, ransomed or released (goodwill +).

Mutants and creatures

Creature Behavior
Rad-rats Swarm. Eat food stockpiles
Glow-hounds Pack hunters at night
Sludge crawlers Underground; burrow through rock
Two-headed cattle Tameable. Milk + meat. Sometimes angry
The Big One Rare boss mutant. Drop: rare parts
  • Night hordes: more mutant attacks at night. Lights reduce them.

Environment

  • Radiation cloud (see 04-economy.md).
  • Acid rain: damages outdoor items and crops.
  • Dust storm: low vision, solar off.
  • Heat wave / cold snap.
  • Fire (from lightning, breaks, cooking accidents).
  • Cave-in, flood underground.

Internal

  • Disease outbreak, food poisoning.
  • Mental breaks, fights, theft, sabotage by a sad survivor.
  • Addiction.

Storytellers

The storyteller is the AI that picks events.

Name Style
Grandma Grit Calm. Long quiet times. For building
The Sheriff Classic. Rising tension, then relief
Doctor Chaos Random. Anything can happen any day

Custom sliders (0–200%)

  • Raid frequency, raid size, mutant frequency, environment events, disease, mental break threshold, resource abundance, radiation cloud frequency.
  • Permadeath toggle.

Event pacing

  • Each event has a cost. Storyteller has a "threat budget" that grows with time and colony wealth.
  • Storyteller avoids two big threats in a row (except Doctor Chaos).
  • Good events too: wanderer joins, trader, cargo drop, "a dog finds you".
In the first demo

Drafting, move/attack orders, cover, 3 melee + 3 ranged weapons, sandbags, scrap turret, rad-rats and glow-hounds, one raider group type, radiation cloud, fire (simple), storyteller The Sheriff + sliders for raid/mutant/environment.

Chapter 07

Story, scenarios and endings

Story structure

  • The player picks one storyline at game start. Each storyline is a chain of 5–7 story beats.
  • A beat unlocks when the colony reaches a condition (tech tier, item, location found). Each beat gives a goal, a story event and often a world-map story location.
  • Story text is short. Systems tell most of the story.
  • Story locations, items and research nodes are tied to the storyline. Other content is shared.

Storyline 1 — Restart the old reactor

Goal: find parts across the wasteland and restart a pre-war power plant. Light up the region.

Pitches (user decision during spec review; options can be combined):

  1. "Keep the Lights On" — The survivors find a reactor operator's badge and a talking maintenance bot named HAL-PH that only speaks in safety slogans. HAL-PH points them to the dead plant. Every part they recover makes HAL-PH more proud and more unhinged.
  2. "Night City Blues" — A cult, the Children of the Glow, also wants the reactor. They want it to melt down, not to run. A race for the same five parts. The colony can fight them, join them, or trick them.
  3. "Power to the People" — Every faction wants the power. The colony must choose who gets it at the end. The ending changes by who you supplied: traders, bureaucrats, or nobody (keep it all).

Storyline 2 — Reach the safe zone

Goal: build vehicles and stock supplies to move the whole colony to a rumored safe place.

Pitches (user decision during spec review; options can be combined):

  1. "Greener Pastures" — A radio loops an ad for "Haven Valley: Clean Air, Low Rent!" Nobody knows if it is real. The colony builds an armored convoy. The final beat is a long journey on the world map with events on the road.
  2. "The Last Bus" — The colony restores a pre-war school bus, then upgrades it into a land fortress. Each upgrade needs an expedition. The bus has a personality (its horn plays one song).
  3. "Tickets, Please" — The safe zone is real, but it only accepts people with "Citizen Papers" from the Last Bureaucrats. Getting papers is a long satire of bureaucracy. Forgery is an option.

Storyline 3 — Signal the orbit

Goal: build a transmitter to contact a space station that survived the war.

Pitches (user decision during spec review; options can be combined):

  1. "Is Anyone Up There?" — A survivor hears voices on an old radio at night. Everyone thinks they are crazy. They are not. The station answers, but it wants something in return.
  2. "Dish Network" — The colony must restore a chain of three radio relay outposts on the world map, then build a giant dish at home. Holding all relays at once is the challenge.
  3. "Final Broadcast" — The station crew is dying too. Both sides must trade knowledge before time runs out. The ending is bittersweet: rescue for some, a legacy for the rest.

Endings

  • Win: complete the final beat. Ending slides show what happened to each survivor (generated from their history, with dark humor).
  • Loss: all survivors dead or gone. A short "obituary" screen.
  • Continue: after a win, the player can keep playing in sandbox mode.

Chapter 08

UI and UX

Principles

  • Desktop-first. Mobile gets an adapted layout, not a copy.
  • Pause is always one action away.
  • Every tile, survivor and item can be inspected.
  • Alerts tell the player what is wrong before it becomes a disaster.
  • Dark humor lives in text, not in confusing UI.

Screens

  • Main menu: New game, Continue, Load, Scenarios, Mods, Settings, Credits.
  • New game flow: mode → storyline → storyteller + sliders → map size + seed → survivor selection (reroll) → start.
  • In-game panels: Work grid, Schedule, Research tree, Health, Survivor details (needs, skills, traits, thoughts, relations, gear), World map, Event log, Trade.

Feedback

  • Small procedural motion instead of sprite animation: bob while walking, flip by direction, shake on hit, tool icon over a working survivor, damage numbers (option).
  • Thought bubbles with icons for needs.
  • Sounds for orders, alerts, combat.

Settings

  • Audio volumes (master, music, SFX, ambient).
  • UI scale, autopause rules, edge scroll, colorblind palette for overlays.
  • Language.

i18n

  • All player-facing text comes from string tables (en.json first).
  • Keys, plurals and parameters in ICU-like format.
  • Generated names use per-language name lists.

Accessibility

  • Text size option. High-contrast overlay option. No info by color alone (icons too).

Chapter 09

Art and audio

Art direction

  • Top-down pixel art, three-quarter view for objects (walls show a front face), flat for floors.
  • Sprite size and palette: chosen by the user from samples (Phase B). Candidates: 16 px, 32 px, or 16 px world + 32 px UI icons.
  • Palette candidates: rust/ochre, toxic green, desaturated grey-blue. One master palette (24–32 colors) for all sprites.
  • Survivors: single-frame sprites for 3 facings (down, up, side; side flipped). Portrait built from layered parts.
  • Motion is procedural (bob, squash, flip, shake). No frame animation for the demo.
  • Lighting: day/night tint + light radius from lamps and fires (shader).
  • Weather: particle overlays (rain, dust, glowing radiation cloud).

Asset pipeline (texel-studio)

  1. assets/manifest.json lists every sprite: id, prompt, size, type (block/item), palette, tileset or not.
  2. tools/art/texel.ts sends jobs to texel-studio (POST /api/jobs) and saves PNG + JSON in assets/raw/.
  3. Claude views each result. Bad results get a sprite.chat refine or a retry with a new prompt.
  4. tools/art/pack.ts packs sprites into a texture atlas with a JSON frame map.
  5. Missing sprites fall back to generated placeholders (colored shapes with a letter), so the game always runs.

Art providers

Provider Status
Local Ollama / llama-swap (default) Works now
OpenRouter (OpenAI-compatible) Config only (OPENAI_BASE_URL + key)

Gemini / OpenAI subscription via CLI bridge Optional, later

Music

  • Adaptive music. The player blends stems by game state.
  • Situations: calm (building), tense (threat coming), combat, night, expedition, victory/defeat stingers.
  • Tech tier changes the style:
  • Tier 0–1: dusty western and folk (slide guitar, banjo, harmonica, fiddle).
  • Tier 2–3: folk mixed with dark ambient synth.
  • Tier 4: dark ambient synth with a hopeful theme.
  • Combat at any tier: drums + tension layer in the current style.
  • Generation: ComfyUI with an audio model (e.g. ACE-Step or Stable Audio Open). Check what is installed first. Ask the user before large downloads.
  • Format: OGG (+ M4A fallback for iOS Safari), loop points in metadata.

Sound effects

  • Footsteps, building, mining, salvage clank, gunfire, hits, UI clicks, alerts, ambient wind, Geiger clicks near radiation.
  • Sources: procedural (jsfxr-style) first, then generated or CC0 packs.

Simulation

  • Deterministic: seeded RNG (one stream per system), fixed tick (60 ticks per in-game minute at 1x is tuned later; target 20 sim ticks per real second at 1x).
  • Data-oriented entities: typed arrays for tiles; entity store with components (Position, Pawn, Needs, Health, Item, Building, PowerNode, Belt...). Systems run in a fixed order per tick.
  • Map: per layer, flat typed arrays (terrain, structure id, roof, room id, temperature, radiation, zone id). Chunked (32×32) for dirty-flag rendering.
  • Pathfinding: A* on the grid with a region graph (regions of up to 12×12 connected tiles) for fast reachability checks and long paths. Cross-layer links via stairs. Path cache invalidated by region changes.
  • Jobs: work givers scan for work by type; survivors pick by priority, distance and skill. Reservations stop two survivors from taking the same target. Jobs are small state machines (go to → pick up → go to → work → finish).
  • Rooms: flood fill on wall/door change, incremental per affected area.
  • Temperature: per room value, exchange per tick by insulation.
  • Power: networks found by flood fill over wires; balance computed per network per N ticks.
  • Belts: item slots on belt lanes, updated in batches.
  • Commands: all player actions are command objects sent to the sim. This allows replays, tests and later multiplayer.

Threading

  • The sim runs in a Web Worker. The client gets a compact snapshot or a diff each frame (transferable buffers).
  • The renderer interpolates pawn positions between ticks.
  • Node runs the same sim directly for tests.

Rendering

  • Chunked tilemap (one Pixi container per chunk, cached when not dirty).
  • Sprite layers: terrain, floor, structures, items, pawns, effects, overlays, UI markers.
  • Culling outside the camera. Zoom levels with integer scaling for crisp pixels.
  • Light pass: a darkness layer with light sprites (additive) for lamps and fires.
  • Performance budget: 60 FPS desktop, 30+ FPS on a mid-range phone with a 128×128 map and 20 survivors.

Saves

  • Save = versioned JSON of the whole sim state, compressed (CompressionStream gzip), stored in IndexedDB.
  • Export/import save file (download/upload).
  • Migrations: one function per version step. Old saves always load.
  • Autosave every in-game day (option). Permadeath: one slot, saved on quit.
  • Cloud saves later: Steam Cloud (if on Steam) or a small paid save server.

Mod support

  • Content (items, buildings, recipes, research, events, traits, creatures, factions, strings) is JSON validated by zod.
  • Mods are folders with a mod.json (id, version, load order, dependencies) + JSON + sprites.
  • Mods can add and override entries by id. No scripting in v1.
  • The base game is itself loaded as a "core" mod.

Dev servers and network access

  • Dev and preview servers bind to 0.0.0.0 so PCs and phones on the LAN can reach them (vite --host 0.0.0.0, also set in vite.config.ts server.host and preview.host).
  • Fixed ports: dev 5173, preview 4173, presentation site served with the preview build.
  • No secrets are served. The game is static files only.

Debug and test hooks

  • window.__game in dev builds: set seed, spawn things, set speed, run N ticks, get state, take snapshot.
  • Headless scenario runner: npm run playtest -- --seed 42 --days 30 prints a report (deaths, mood, resources, tick time).
  • Playwright e2e: desktop (1920×1080) and phone (390×844) viewports. Screenshots and short videos saved in artifacts/.
  • CI-like local script npm run check = lint + typecheck + unit + scenarios + e2e.

Performance targets

Metric Target
Sim tick (20 survivors, medium map) < 3 ms on desktop
Headless 30 in-game days < 60 s
First load (web) < 5 MB before first frame

Chapter 11

Roadmap

Gates (user decisions)

  1. Spec approval — no game code before this.
  2. Art choice — user picks sprite size and palette from samples.
  3. Demo review — user plays the demo and gives feedback.

Demo milestones

Each milestone ends with: tests green, a headless scenario run, Playwright screenshots checked, a git commit, and a CHANGELOG entry. No check-ins with the user until the demo.
